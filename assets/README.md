# PHANTOM 2.0 assets

- `logo.svg`: vector logo used inside the app by default. Replace this file with your SVG logo while keeping the filename.
- `logo.webp`: alternative raster logo. To use it, set `APP_LOGO_FORMAT = 'webp'` in `src/constants/config.js`.
- `icon.png`, `adaptive-icon.png`, and `splash.png`: Expo native launcher/splash assets. Native app icons should remain PNG; SVG and WEBP are supported for the in-app brand logo.
- `fonts/thmanyahserifdisplay-Medium.otf`: the bundled Arabic display font.
